# App Store Connect 登録内容

3級・2級それぞれについて、App Store Connect に入力する内容をまとめたもの。
**アプリが2つあるので、すべての項目を2回登録する。**

コード側の値（バンドルID・課金プロダクトID・価格）は `FPn/AppFlavor.swift` と
`FPn/Products.storekit` が正で、ここはそれを転記したもの。**食い違ったらコード側に合わせる。**

> **文字数の上限**（全角・半角を問わず1文字と数える）
> App名 30 / サブタイトル 30 / プロモーションテキスト 170 / キーワード 100 / 説明 4,000

---

## 0. 使ってはいけない表現

審査と表示の両方に効くので、文言を変えるときもここは守る。

| 使わない | 理由 |
| --- | --- |
| 「過去問」「本試験問題」 | 収録しているのは公開されている試験範囲に基づく**独自作成の問題**。過去問そのものではない |
| 「日本FP協会」「きんざい」「金融財政事情研究会」をApp名・サブタイトル・キーワードに | 他者の名称を検索誘導に使うことになり、提携していると誤解させる。**権利表記の注記としてのみ**事実を述べる |
| 「合格保証」「必ず受かる」 | 効果の保証にあたる |
| 「投資・節税のアドバイス」 | 本アプリは学習用であり、投資助言・税務相談を行うものではない |

カテゴリに「ファイナンス」を選ばないのも同じ理由（§1参照）。

本アプリは試験対策の学習アプリで、個別の助言も取引も行わない
（その旨はアプリ内の「このアプリについて」にも常設してある）。

続いて正解の理由、さらに全選択肢の解説を読めます。

問題一覧での閲覧・検索・解説の読み直しは、期間の前後を問わず常に全問できます。

月額・年額の課金と広告はありません。

■ 通信しません
学習の記録は端末内にのみ保存され、外部へ送信されません。
機内モードでも地下鉄でも、動作は変わりません。

## 5. App のプライバシー

**「データを収集していません」** を選ぶ。

本アプリは通信を一切行わず、学習履歴は端末内の SwiftData にのみ保存する。
外部へ送信するデータが無いため、収集データもトラッキングも「なし」で正しい。
この宣言はアプリに同梱している `PrivacyInfo.xcprivacy` の内容とも一致している
（`NSPrivacyTracking` = false、`NSPrivacyCollectedDataTypes` = 空）。

なお UserDefaults は Apple の Required Reason API に該当するため、
利用理由（CA92.1／このアプリ自身の情報の読み書きにのみ使用）をマニフェストで宣言済み。
これはアプリ側の宣言であって、App Store Connect のプライバシー質問とは別物。

## 8. 提出前チェックリスト

コード側と App Store Connect 側の値がずれると、気付きにくい壊れ方をする。
提出前に次を突き合わせる。

- [ ] バンドルIDが `project.yml` の `PRODUCT_BUNDLE_IDENTIFIER` と一致している
- [ ] 課金の製品IDが `FPn/AppFlavor.swift` の `unlockProductID` と一致している
- [ ] 課金の価格が `FPn/Products.storekit` の `displayPrice` と一致している
- [ ] **サポートURL・プライバシーポリシーURLが実在し、`FPn/AppFlavor.swift` と同じURLになっている**
- [ ] スクリーンショットを**その級のアプリで**撮り直している
- [ ] 説明文の級（3級/2級）と出題形式（○×式・三答択一式／四答択一式）が正しい
- [ ] 説明文の法令基準日が `FPn/AppFlavor.swift` の `lawBasisDate` と一致している
- [ ] **収録問題の人手レビューが済んでいる**（未レビューのまま公開しない。README参照）

最後の項目が最も重要。国家検定の対策アプリで解説が誤っていると、
利用者は誤った知識を「正解」として覚えることになる。
